NEED TO KNOW

Frequently asked questions.

Some quick answers about the PRIZEN experience.

PRIZEN is a gaming and community project designed to bring people together and share community updates and potential reward opportunities.
This website does not confirm any active giveaway. Check official announcements for current events, dates, prizes, eligibility, and entry instructions.
Use any Join Discord link on this page. If the invite has expired or reached its usage limit, a server administrator will need to create a new invite.
Check the official rules for each event. Never send money, passwords, account recovery codes, or login credentials to claim a prize. Be cautious of anyone asking you to pay a fee to release a supposed win.
The selection method should be stated in each official event's rules. This website does not automatically select winners or track entries.
This static page has no account registration, entry form, or server-side database. Clicking the Discord links takes you to Discord, which operates under its own policies.
